# 0.5.1 三个功能开关 — 针对性实机测试

只测试本轮控制项，无需重测每个音效包/波形。全局两开关保持开启，先使用当前绑定的单只手柄。

1. F6「设置」顶部应有星级庆祝·震动、星级庆祝·音效、危险预警·震动；文字/滚动不遮挡。切换偏好，F10全关再全开、重新打开菜单及重启后应保留三项选择。
2. 星级震动关、音效开：真实关卡达到一个尚未触发的星级，只播放庆祝音效，无该次星级震动。两项反过来后，在下一未触发星级或重开关卡测试，应只有星级震动。两项都关时仍有普通上菜/Combo反馈；重新开启不补播旧星级。
3. 危险预警关：过度烹饪/真实起火均不自动震动，拒单/订单超时不因此关闭。若现场仍有火，重新开启不会补播首次起火，持续提醒至少等5秒；默认关闭的FoodBurned不会随组开关被启用。
4. 三项功能关时，手动星级试音/试震和火警试震仍可用。这些按钮明确绕过自动功能开关，但关闭对应全局开关后不能输出该通道。
5. 正常退出游戏，报告完成的步骤和异常。日志记录三项功能变化及实际事件；未做的步骤直接说明。原v1.6真实事件验证尚缺的场景保留在原清单，不从菜单预览推定通过。
