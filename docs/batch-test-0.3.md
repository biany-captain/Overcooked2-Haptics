# 0.3.0 整批实机清单

本轮为用户已确认的候选手感。软件/模拟通过不能替代下列实际游戏验收，不会自动修改手感。

## 1. 主菜单 / 手动暂停中的F6预览

打开F6，分别试通用、接住双段、顺序/乱序/未分类、Combo ×2/×3/×4及一到四星。列表可滚动；Combo/星级标签行跟随上方对应总开关，手动预览独立于自动开关。

- 默认星级为震动＋音效、音量65%。比较声音是否清脆、过响，四星是否太长。
- 切仅震动：一星应多一段轻尾脉冲；切仅音效：星级预览不驱动马达；关闭模式：星级不播放。
- 音量0/50/100可比较，只影响MOD音效。游戏本体静音时不应被绕过。
- 手动暂停仍可明确点击试听，声音/震动按实时结束。关闭F6、F10关闭总开关、Alt-Tab失焦时应停止；返回游戏不补播。
- 页面不自动暂停，只屏蔽当前绑定厨师，关闭后操作恢复。界面文字若仍有裁切请指出具体位置。

## 2. 实际上菜 / Combo

先关闭星级自动庆祝，便于单独听摸上菜波形。在有多种订单的普通关卡：

1. 连续顺序上菜约6次：×1普通双震；×2、×3、×4使用对应候选，后续保持×4，不无限增强。
2. 乱序但成功上菜一次：偏左低沉单震；恢复顺序一次应依据游戏实际倍率重新开始。
3. 真正上菜失败一次：220ms低频反馈，不能与乱序混为一类。
4. 在会发生订单超时的关卡等一次超时：250ms双马达，不能连着补播旧奖励。
5. 关闭Combo分级后，顺序/乱序反馈仍保留。每次真实成功交付只有一套反馈。

次数不同可以如实说明，不必为了日志勉强重复。

## 3. 实际星级

开启星级并正常重开关卡。门槛由当前关卡读取，无需逐关手填。只需对一个实际测试关卡核对画面/分数与提示是否一致。

- 首次跨线触发；同一关分数掉下去再涨回来不重复。
- 同盘上菜同时达标时，星级取代上菜/Combo，不叠加。
- 单盘跨过多星仅播最高一档。例如已采集的教程比分0→28→76，门槛20/40/60，应先一星、再三星；没有单独二星并非漏报。
- 退出/切关/重开不继承上一局已播状态；中途开启MOD不补播已达到的星级。
- 没有实际NGP第四星环境时，四星自动触发仍记未验证；F6四星试听只证明预览。

## 4. 回报信息

退出游戏后回复：完成哪些步骤、实际操作顺序、哪些波形相似/太弱/太强、声音是否舒适、是否重复或残留。日志由开发端只读检查，不需要手动抄所有关卡门槛。

触觉盲测尚未完成。如有同伴，可让对方随机点击约10次、你不看标签猜事件，记录“实际事件→猜测”；单人先做候选比较并如实保留盲测未完成。任何调整先提出参数建议，经确认后再改。
