# 三个功能开关 — 0.5.1 增量设计

2026-11-22，用户选择“三个开关，危险预警合并”。这是对v1.6“细项仅cfg”的已确认调整；不恢复逐事件倍率或大量开关。

- 保留震动总开关/总强度、音效总开关/相对音量。在F6「设置」顶部新增星级震动、星级音效、危险预警震动，默认开启；每个星级不再各设一项。
- 星级两通道分别受其功能开关与相应全局开关约束。只开音效不出星级震动，只开震动不出星级音效；两者都关时正常上菜/Combo照常仲裁，不让关闭的庆祝吞掉普通反馈。禁用期间经过的星级不补播。
- 危险组统一控制近烧焦、已烧焦、首次起火和持续火警震动。已有逐事件cfg继续有效，尤其FoodBurned仍默认false；打开危险组不会擅自启用它。拒单与订单超时不在此组。
- 关闭功能立即停止相关的现有通道，不停止另一通道或其他种类反馈；重新开启不补播旧事件。持续火警重新开启后至少等待原5秒间隔。
- F10仍全局全关/全开，保留这三个偏好。手动测试继续绕过功能/逐事件开关，但服从全局开关、冷却和预算；在功能关闭时仍可明确点击比较。
- 原Stars.Enabled迁移为Stars.HapticsEnabled和Stars.AudioEnabled；存在明确的新键时优先新值。Hazards.HapticsEnabled为危险组；保留强度、音量、绑定、波形和音效包，不新增依赖。

取舍：三项比逐事件控件更简洁，不能在菜单单独关闭持续火警；用户未选择“再拆持续提醒”的四项方案。先扩展现有配置和统一协调器，不重做引擎/音乐/事件Hook。自动行为与手动预览分开验证，真实游戏和硬件结果待用户测试。
