# 0.2.1 管理页验收

一次启动即可检查。测试后恢复希望保留的开关状态，修改会立即保存。

1. 按 F6：出现中文管理页，有总开关、通用测试、五类事件开关/试震、关闭按钮；打开本身不震动。
2. 点通用测试及各类试震，感受原80ms及各已确认节奏。每次间隔约一秒。预览是手动输出，不是实际游戏 Hook。
3. 关闭总开关：所有测试按钮停止输出。按 F10 再开启，菜单总开关应同步；菜单总开关也能即时控制全局输出。
4. 关闭一个事件的复选框后，它的手动试震仍可预览；关闭菜单后该类真实游戏事件不应自动震动。恢复复选框后自动触发应恢复。
5. 在关卡中打开菜单，尝试移动/操作当前厨师应被阻止；F6或×关闭后操作恢复。关卡不会自动暂停。
6. 手动暂停游戏，再打开F6并点试震：应能播放并正常停止。关闭菜单后原暂停状态仍保留。
7. 最后可回到主菜单并把F6窗口留在屏幕上，以便只读检查中文和布局；实际操作由用户完成。

若有异常，记录菜单显示/鼠标、试震、总开关同步、单事件开关、本地输入恢复、暂停试震各项情况。旧0.2已保存，可回退。
