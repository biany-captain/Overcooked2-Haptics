# 0.4.0 整批手工验收

软件检查不代表音源已在游戏正确播放。设备沿用黑武士5 Pro/2.4G XInput/Pad0→XInput0；保留你的当前音量和强度。

1. 主菜单F6 → 星级测试：默认包应显示「欢乐卡通爵士」。依次点一到四星“试音”，应分别完整约0.98/1.49/2.16/3.25秒，第四星后半有少量合成欢呼/掌声。音量可比较65%与45%，无需强行改当前值。
2. 每档“试震/同时测试”分别比较：默认窗口180/285/425/660ms；最高星也不随音乐持续震。总强度0–100%、每项0–200%，0%不震，恢复100%事件倍率后再比较。自定义波形可能不同。
3. 展开下拉，切换「清脆奖励音」，再听同档，应换成旧短铃；切回欢乐，关闭/重开F6与重启游戏，选择应保存。音乐中切包必须停旧声音，不叠播。
4. 在手动暂停中试听，结束后停音停震；试听四星时分别检查F10关闭、关菜单、失焦及接收器断连会停止，恢复不会补播。小窗口/较短高度展开下拉，所有控制可通过滚动访问，不能重叠裁字。
5. 普通关卡顺序上菜并达到真实门槛，检查一次交付只有一套反馈；单盘跨多星只最高星。失败/超时发生在音乐中应抢占；普通投掷不应停止音乐尾声。
6. 退出游戏后提供已测项目、曲目辨识度、响度和音震同步的主观反馈。未解锁NGP不要求额外解锁，四星可先用菜单试听。真实二/四星、NGP、危险Hook、本地多人和在线仍按证据记录未测试。

可选故障测试：退出游戏，备份后暂时改名某个WAV再重启，该星应只缺声音、震动与游戏正常；恢复文件后重启恢复。无需删除文件。盲测≥85%是目标，尚无真人测试结果，不作通过声明。
