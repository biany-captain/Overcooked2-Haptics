# 本地星级音效包

0.4.0启动时预载四首PCM WAV。F6 →「星级测试」→「音效包」下拉选择，统一影响一到四星的自动声音及手动试音；每档仍可分别试音、试震、同时测试。切包即时保存并停止旧输出，不改自动模式或个人音量。关闭总反馈时仍可选择包，声音测试需打开总反馈。

默认「欢乐卡通爵士」为用户提供的四首完整乐句，长度0.98/1.49/2.16/3.25秒，第四星含合成卡通欢呼/掌声；原「清脆奖励音」保留。仅震动模式不播放音乐，但会使用已配置的星级震动。未提供素材的「超燃」不作为可用选项显示。

## 新增音效包

安装位置为 `BepInEx/plugins/OC2Haptic/audio/<唯一包ID>/`。每个目录放四个WAV和UTF-8文本 `pack.ini`：

```ini
Name = 超燃
Star1 = star_1.wav
Star2 = star_2.wav
Star3 = star_3.wav
Star4 = star_4.wav
```

以上仅演示清单格式，不随附「超燃」素材。文件名必须在同目录，不能用绝对路径或上级目录。支持PCM signed16-bit、44.1/48kHz、单/双声道；建议48kHz立体声。每首最大3.5秒。当前不支持MP3、OGG、浮点WAV或联网下载。新包连同许可/署名放好后重启游戏，自动出现在下拉框；不必重新编译DLL，也没有游戏中扫描/解码。

源码目录对应 `assets/audio/<包ID>/`；打包脚本将它复制到插件旁。每个新增包须提供来源、授权、原始文件SHA256与编辑记录。当前包的记录在 `assets/audio/SOURCES.md`，许可说明与原始MIDI/制作脚本一起分发。其音频按所附GPL-2.0声明处理，不能标作CC0；插件代码许可仍待项目作者选择。

## 降级与兼容

所选包ID不存在、某一文件缺失/损坏或游戏SFX组未就绪时，相关声音不可用，已有震动与游戏继续；不悄悄改播其他包。检查日志的 `Reward audio prepared` / `Selected reward audio unavailable`。在启动后删除磁盘WAV不会立即移除已预载Clip，测试损坏/缺失需要重启。不要修改原游戏资源。

`StarFeedback.SoundPackId`记录所选包；`SoundVolume`沿用当前值，默认只对新配置为0.65。旧 `MaxSoundDurationMs`只约束原清脆生成音，不截断外置音乐。v1.4正式震动时间轴与包内保留的JSON候选不同：用户已选择180/285/425/660ms短序列，仍受总强度、每星倍率、850ms上限约束。自定义旧波形不强制覆盖。

分数Hook只提交事件，Unity Update播放预载声音并按单调时钟推进马达。没有固定120ms等待；增加了至下一Update的帧调度，实际声卡/马达误差仍需实测。较高星中断旧音乐并停止旧马达任务后启动新序列，不并播；当前采用立即停止，未加入未经试听确认的淡出效果。普通动作不会主动停止音乐尾声。

失败/订单超时可中断庆祝；关闭菜单、切包、暂停、失焦、禁用、切关、断连或卸载会停止自己的音震，不补播。断连查询在游戏Update中最多每250ms一次；主线程阻塞或设备故障时不保证物理停止时延。新的真实起火/烧焦Hook和多人映射尚未加入，不能用模拟抢占测试冒充这些实机能力。
