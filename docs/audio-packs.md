# 本地星级音效包

0.4.1启动预载12首PCM WAV。F6 →「星级测试」→「音效包」下拉统一选择一到四星，每档可分别试音、试震、同时测试。切包立即停止旧输出并保存，不修改自动模式或震动强度。

| 包ID | 菜单名称 | 一至四星长度 |
|---|---|---|
| turbo_swing | 超燃卡通大乐队（默认） |1.05/1.57/2.30/3.85s|
| champion_fanfare | 冠军加冕号角 |1.13/1.70/2.48/4.05s|
| kitchen_rock | 厨房摇滚派对 |1.01/1.53/2.35/3.80s|

三套均为用户提供的Ultra Victory v3文件，原样接入，不含欢呼/掌声。用户明确要求删除旧欢乐卡通爵士和清脆铃音；两个旧ID停止发现/播放，旧选择迁移到turbo_swing。无可用文件时声音不可用，不再使用旧生成铃音。

## 游戏音量与自定义调节

自有2D AudioSource继续路由到原游戏SFX混音组，游戏主音量、音效滑杆及静音决定最终声音。F6的「相对音量」默认100%，0–100%可调，系数只应用一次，不改变游戏BGM、原AudioSource或Mixer。100%表示文件原有电平乘游戏音效设置，不表示与每个游戏声音听起来一样响。

新配置SoundVolume=1。普通升级保留已有自定义值；本机用户已明确要求从0.7006757改1。自动模式保留：若为「仅震动」，实战仍不播放音频；独立试音可用，实战听音乐须自行选「震动＋音效」或「仅音效」。

## 新增本地包

放置 `BepInEx/plugins/OC2Haptic/audio/<唯一包ID>/`，包含四WAV和UTF-8 `pack.ini`：

```ini
Name = 自定义风格
Star1 = star_1.wav
Star2 = star_2.wav
Star3 = star_3.wav
Star4 = star_4.wav
```

文件名必须在同目录。支持PCM signed16-bit、44.1/48kHz、单/双声道，建议48kHz立体声；单曲最大5秒。重启识别新包，不在Hook扫描/读取/解码。当前不支持OGG/MP3/浮点WAV/联网下载；素材附带JSON仅保留为制作来源，本轮采用上述WAV清单，不实现逐星混搭或外部欢呼分轨。

源码目录对应assets/audio/<包ID>；打包复制到插件旁。保留来源、许可、原始哈希和编辑记录，见assets/audio/SOURCES.md；用户自备包ID与未知选择保留。不要使用已退役的joyful-cartoon-jazz或crisp-reward名称。供包说明记录TimGM6mb音色库GPL/署名及输出许可边界，不称CC0；MIDI和必要渲染源码随资产保留，非运行依赖。

## 停止与降级

缺失/损坏文件或无可用包时，只是相应声音不可用，震动与游戏继续，不自动改播其他风格。检查Reward audio prepared/Selected reward audio unavailable日志。启动后删文件不影响已预载Clip，缺失测试须退出并重启；恢复文件后同样重启。

较高星替换旧庆祝并取消旧马达任务；同次上菜只有一套最终反馈。普通动作不停止音乐尾声，已有失败/超时可以抢占。切包、关菜单、F10、失焦、暂停、切关、断连或卸载停止自己的音震且不补播。断连Update最多每250ms查询，主线程阻塞/设备故障时不能保证物理停止延迟。

音乐可长达4.05秒，正式v1.4马达窗口仍180/285/425/660ms，最大850ms。保留自定义波形/强度。软件计划起点不等于声卡/手柄真实同步测量；本轮新音乐与游戏音量跟随待实机，火灾Hook、本地多人和在线继续后置。
