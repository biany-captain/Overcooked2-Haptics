# 0.4.2 精简菜单实机检查

重新启动游戏，按F6：

1. 顶部只有震动总开关/总强度、音效总开关/相对音量。逐事件开关、倍率和四种模式消失；所有文字完整，两个页签和三套音效包仍可用。
2. 两路开启，在星级测试点击四星“同时测试”。播放中关闭震动，音乐应继续；重新开启不补震。
3. 再做一次四星同时测试，立即关闭音效，震动应继续到原本结束。关闭一路时对应独立测试及同时测试按钮不可用；另一条独立测试可用。
4. 保持只有一路开启，按F10应全部关闭，再按应全部开启；F6始终可打开。关闭菜单/失焦应停止，不补播。
5. 自调两个总滑杆及音效包，重开菜单/重启后保存。可在关卡简测投掷和上菜，音效单独开启时不应产生动作震动。

菜单不自动暂停，测试前可手动暂停。关闭音效不改变原游戏声音。反馈已测步骤与异常即可；未执行的项目单列。
