# 0.4.1 三套音乐与游戏音量测试

1. 重启游戏，F6→星级测试，默认应为「超燃卡通大乐队」，下拉另外两项为「冠军加冕号角」「厨房摇滚派对」。旧欢乐/清脆应消失。
2. 三套分别逐星试音，四星应完整约3.85/4.05/3.80秒且没有旧模拟欢呼。比较是否比旧音色满意、长音乐是否打扰；切包不应叠播。
3. 相对音量应100%。在游戏设置调低主音量或音效音量、静音后再试音，MOD应跟随；游戏音量恢复后，F6相对音量也能单独调小/静音并保存。音频实际大小仍以试听为准。
4. 当前保留的自动模式为「仅震动」；独立试音不受影响。实战要听新曲，先自行选「震动＋音效」。在普通关卡确认达星仍只选一套反馈，未知/未解锁第四星不硬触发。
5. 同时测试时马达仍在180/285/425/660ms结束，不随4秒音乐持续震。检查F10关闭、关菜单、失焦/暂停/断连停止且不补播；手动暂停中仍可明确点击试听。

完成后退出游戏，回复已测项目、最喜欢的风格及异常。无NGP条件先只菜单测四星。不要将全菜单试听当作真实四星/盲测/仪器延迟验收。
