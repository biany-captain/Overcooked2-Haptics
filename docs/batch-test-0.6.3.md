# 0.6.3共享提醒实机清单

候选规则已由用户确认；软件通过不代表以下实机项目已验收。正常加入他人房间、本机单厨师/单手柄即可，不要求固定顺序或次数；未遇到的项目直接记未测。

- 日常交付：本人普通/乱序/Combo有对应个人反馈，队友普通上菜仍安静。方便时让队友接手自己放台面的盘子，确认不因旧持物记录误播个人反馈。
- 达星：任意本队队员促成首次达线都可庆祝，同一次本人交付不叠加普通/Combo；掉分回升不重复、跨多星取最高、中途加入不补播。一二星无额外声音，三四星继续原音轨与短震。
- 拒单与超时：本人或队友真正错误上菜触发一次长低频负反馈；订单超时同样共享。之后本人成功上菜仍正常，不因失败回执陷入持续静默。
- 危险：真实近烧焦/起火有本队反馈；持续火灾最多每5秒提醒，蔓延不连续重复首警，全部扑灭后停止。不需要开启默认关闭的FoodBurned。
- 控制：原星级音效/震动、危险震动、全局总控和F10继续有效。方便时观察真实危险/独立负反馈中断庆祝；危险震动关闭时不震，但仍可停庆祝音。未自然遇到该组合可记未测。
- 退出后读取自身日志，区分TeamFeedback/TeamHazard与PersonalDelivery来源。日志中的接收厨师不等于共享事件的操作者；计数是排程证据，不能替代触感观察。
