# 精简震动与音效控制

2026-11-21。用户已确认本次方案；直接聊天中的最新决定优先于历史需求文档中的候选配置。

- 菜单只保留震动总开关、总强度，音效总开关、相对音量；保留两个页签、音效包和全部测试按钮。
- 移除逐事件开关、Combo/星级开关、事件/星级倍率以及四种自动模式。旧额外事件倍率恢复100%，既有波形、节奏、优先级和Combo基准强度不变。
- 两路独立控制真实事件与手动测试。关闭某一路立即停止该路；另一条正在播放的输出继续。打开不补播。
- F10仍一键全关/全开：只要任一路开启就全部关闭；全部关闭时再按会全部开启。F6始终可以打开。
- 默认两路开启。首次升级用旧总开关和星级模式迁移两路状态；已经存在的新开关优先。保留总强度、相对音量、音效包、设备绑定、快捷键和自定义波形。
- 音效仍跟随游戏主音量/SFX，保留三套12首原始WAV；不增加新声音、危险事件或多人功能。

方案比较：仅隐藏倍率最省改动，但多层开关和模式依然重复；保留两个总控加总滑杆既简洁又允许调节，用户选择此方案。仅保留两个开关会失去用户已要求的强度/音量微调，因此未采用。

验收：配置迁移、两路独立停止、测试不能绕过总控、F10两次切换及暂停/失焦停止通过软件检查；菜单排版与真实设备结果由用户实测。
