# 0.6.0 / v1.7 星级整批测试

默认simple/cool已接入；先保留震动与音效两总控、星级两功能开关开启，音量维持100%。无需重测整套非星级波形。

1. F6→星级测试：一二星只有试震且没有声音，分别轻单段/双段；三星约0.9秒短音＋250ms双段；四星约10.67秒完整音乐＋仅开头630ms震动，之后马达停止。
2. 四星下拉依次试自定义cool与原三套短曲，再切回。三星声音应始终是simple、不随四星变化；选择重开菜单/重启后保存。两总控/三个功能开关继续独立，手动预览仍绕过功能开关但服从总控。菜单文字/滚动完整。
3. 普通关卡真实从低分达一/二/三星，确认只播对应反馈，一二星无额外声音；同单达星＋Combo升级不叠加。一次跨多星只最高，掉分回升不重复，重开新局可以重新达标。未解锁四星可先仅菜单试听，注明未测真实四星。
4. 四星音乐期间游戏BGM应暂时静音，游戏音效保留；音乐自然结束或被中断后，游戏BGM恢复原来的状态。三星/仅试震不应静音BGM。检查游戏原音乐音量未被保存成0。
5. 四星音乐播放时，普通/Combo可在短震结束后继续；真实起火/过度烹饪或另一次拒单/超时应立即停止庆祝音乐并执行已有负反馈，不补播。关闭危险震动后，真实危险仍停音乐、恢复游戏BGM但不播危险震动。菜单火警试震只用于比较波形，不作为真实抢占或Hook通过的证据。
6. 音乐播放期间F10、关菜单、失焦/暂停、切场景应停止并释放BGM覆盖；主菜单/手动暂停中明确点击试听允许播放，但仍能正常停止。

正常退出后回复已测项目/异常、强弱与音量是否舒适，以及cool是否满足你希望的欢呼/掌声。未做的步骤直接说明。日志、人工体感、模拟/编译证据分别记录。
