# v1.6候选批量实机测试（0.5.0-alpha）

先正常退出旧版、备份自身DLL/cfg，升级后手动启动。新反馈候选尚未验收；本轮保留标准低/高通道，不是之前同值/左电机填充草稿。实际游戏Pad与XInput绑定沿用已确认值。

## 1. F6手感比较

按F6，先看总强度是否保留当前个人值。依次测试成功、乱序、真正拒单、订单超时、Combo×2/3/4、烧焦预警、起火及持续火警。每项等约2秒，起火/持续提醒同类至少等5秒；拒单/超时有更长冷却，超预算时可能不播放，不能靠快速连点判断漏触发。可手动暂停测试，失焦/关闭菜单停止。

目标是：成功一次短促；乱序轻双段；拒单沉重衰减；超时分离两击；升级节奏可区分，起火最重但不会一直开马达。报告哪一项偏弱/过强/难区分。星级/音乐整体已通过，不要求重新全套验收；本轮只回归一个星级及抢占即可。

## 2. 真实上菜与Combo A

进入普通故事/Campaign可多订单关卡，按顺序交付至×4，再继续约2单；中间任意达星可以替代该次交付反馈。观察：首单普通成功；真实升级才有×2/3/4节奏；保持同档/封顶后普通短震；一单只有一套。

跳过首张有效订单乱序成功一单，再恢复顺序；错误交付一单，等待一单真正超时。记录实际顺序、HUD倍率和听/震到的种类，次数不同无需重做。没有上菜反馈时先保留日志，不把未知映射改成全手柄广播。

## 3. 新危险Hook与停止

在可以正常燃烧的故事关卡，让一个锅进入游戏已有过度烹饪警告，再出现真实火焰：观察近烧焦提醒时机、首次起火长反馈。保持火势约11秒，提醒应最多每5秒一次，火势蔓延不连震；扑灭全部火源应停止火警及后续提醒。可对比取走锅/换内容、暂停/失焦/切关与拔插是否停止、不补播。

Ruined/已烧焦本轮只采集客户端证据，自动默认关闭；菜单试震不等于真实烧焦事件验收。只在实际观察到独立状态和时机后，再确认是否启用。

若方便，在F6四星音乐播放时测试拒单/超时只能通过真实关卡事件（菜单开时自动事件静音），或用菜单的候选负反馈试震观察停止音乐；起火应抢占，普通成功/投掷不应切断音乐。
