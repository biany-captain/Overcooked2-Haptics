# v1.6 本轮实施约定

2026-11-22，正式需求haptic-redesign-v1.6.md、codex-v1.6-incremental.md及config/haptic_patterns_v1.6.json，与本轮聊天确认共同约束。

- 使用标准XInput低/高两通道，不采用上一轮同值输出或左电机填充候选；不重建项目、不删除原星级波形/音乐、F6/F10及音效包。
- 首发候选为balanced_extended_negative。正式采用Combo A，仅可信等级上升时分级；同档/封顶成功为90ms普通短震。原有自定义配置保留，已知旧默认精确迁移；固定0.85旧Combo额外比例移除，JSON命令只乘总强度，避免双重衰减。
- 无可信先前连击状态的wasCombo=false不认定乱序，降级普通成功。真正拒单/超时独立语义。
- 用户确认优先级例外：同一单达星仍只播星级，但后续独立拒单/超时可立即停止当前庆祝音震；不让长音乐挡住新的事故。JSON静态优先级保留，协调器/输出层明确处理该跨事件例外。
- 新拒单430ms、超时505ms、警告450ms、起火820ms与持续提醒470ms为候选；负面/危险模式允许至950ms，普通500ms和星级850ms约束保留。
- 中央FeedbackCoordinator在已有引擎/音频之上统一映射、过时、去重、分类冷却、预算及取消。预算按非零命令有效排程时长估算，不冒充物理功耗；每设备10s普通1200/负面2200/紧急2500ms。火灾首次不受普通预算阻碍，仍有紧急硬预算。无旧事件补播。
- 当前已验证同步消息立即仲裁，维持用户已批准行为；不为未出现的异步路径统一等80ms。新来源须有可信关联后再启合并窗口。
- 可靠单设备场景继续映射；多人/在线未知操作者的Combo静默。普通交付及危险只在明确队伍回退配置下作用已绑定设备，不猜索引、不广播。
- 起火采用场景内事件组上升沿，蔓延不逐火焰狂发；持续至多每5秒一次且cfg可关闭，最后火源消失即取消当前火警，暂停/失焦/切关不补播。近烧焦按实体状态边沿；已烧焦保持默认关闭待真实验证。
- JSON作为版本化预设输入，与运行默认逐项校验；运行使用原BepInEx cfg/波形解析，不引入JSON运行库。quiet/dramatic可选风格暂不增加菜单或改变默认。
- 菜单保持两总控/两滑杆；细项cfg，投掷/接住默认关闭但保留Hook及试震。保留当前音量/总强度/绑定/音效包；新用户总强度0.75、相对音量100%。
- SDL3只提供可扩展的设备身份/独占输出契约与模拟测试，不打包原生SDL、不自动双后端枚举。不同后端不允许领取同一已知设备，身份不明确时保守拒绝并行。

替代方案：两路同值更容易覆盖单有效通道，但会失去本轮高低频语义，用户选择标准双通道。恢复大量UI调节项有灵活性但与精简要求冲突，用户选择cfg细项。重做全系统或强加新音频/SDL依赖成本更高且无必要，保留既有模块增量接入。

验证分层：纯逻辑、实际BepInEx配置、实际游戏引用编译、静态IL、原生游戏、设备体感分别记录。Hook探针/新自动反馈必须由用户手动在真实关卡验证；不自动操作游戏，不将模拟或编译当成实机通过。
