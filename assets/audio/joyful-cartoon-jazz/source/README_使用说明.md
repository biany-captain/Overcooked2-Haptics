# Overcooked2-Haptics — 四星庆祝音乐成品包（原创编曲 v1.0）

制作日期：2026-11-21  
用途：游戏进行中 **首次达到 1～4 星分数门槛** 时的奖励音乐，非游戏背景循环音乐。

## 试听 / 使用

| 星级 | 音频（WAV/OGG 同名） | 长度 | 音乐风格 |
|---|---|---:|---|
| 1 ⭐ | `star_1_playful_spark` | 0.98 s | 轻快钢琴、木琴、晶莹点缀；短促俏皮 |
| 2 ⭐⭐ | `star_2_bouncy_skip` | 1.49 s | 跳跃单簧管、马林巴、钢琴；更活泼 |
| 3 ⭐⭐⭐ | `star_3_brass_victory` | 2.16 s | 小号、长号、钢琴与鼓；明显胜利感 |
| 4 ⭐⭐⭐⭐ | `star_4_grand_kitchen_party` | 3.25 s | 爵士铜管合奏 + 鼓 + **少量合成卡通欢呼与掌声**；最热闹 |

- `audio_wav/`：48,000 Hz、16-bit PCM、立体声；可在 Windows 常见播放器里试听。
- `audio_ogg/`：48,000 Hz、OGG Vorbis、立体声；适合 Unity 项目资源加载。
- `midi/`：四首**原创乐句**的 MIDI，可继续调整旋律与配器。
- `preview_all_4_stars.wav`：四首串联试听，星级间隔 0.45 秒（**不要**将此文件接入游戏）。
- `docs/star_celebration_config.json`：星级对应文件名、音量、震动提示点和冲突策略，供 Codex 参考。
- `build_music.py`：可复现的离线编曲与渲染脚本；依赖 Python、FluidSynth 库和 TimGM6mb SoundFont（此音色库不随包分发）。

## 设计约束

1. 统一音乐风格为 **欢乐卡通爵士 / Swing（168 BPM，F 大调中心）**，但不同星级主奏乐器、乐句和节奏不同。
2. 星级越高，编制越丰富、更热闹；不能单纯放大音量充当等级区分。
3. 4 星仅加入**少量、合成的**卡通“耶／呜呼”式欢呼与鼓掌杂音。**不是自然人群真实录音**，使用前请先试听是否满足你的拟真度偏好。
4. 游戏里默认**音量 65%**，这是 Unity 音频增益设置，不是已烘焙成 65% 的文件。
5. 这些短音乐均为**本次新编曲的音符**，没有剪辑或采样《Fancy Day》及其他现成商业音乐。
6. 暂未做实际 Windows/Steam/游戏内听感和震动验收。若游戏 BGM 盖住音效，应实测后调整 MOD 混音总线或设置。

## 将声音交给 Codex

请将 `audio_ogg` 或 `audio_wav` 的四个文件复制到 MOD 的资源目录；由当前游戏版本决定使用内置资源、AssetBundle、或运行时解码的实现方式。**不要假设游戏已有某个公开声音接口**。

在一次上菜同时触发 Combo 和星级时，必须由同一个事件调度器合并：只播放最高达标星级的庆祝，不叠加 Combo 声和普通上菜声。只有在当前关卡 **真实、可验证** 的星级阈值被跨越时才播放，一局每星默认最多提示一次。紧急警告可停止或压低庆祝声音并立即抢占马达。暂停/重开/离开关卡时需要正确清理播放状态。
